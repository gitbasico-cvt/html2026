## 📖 Sobre o projeto

O **Estoque Fácil** é um aplicativo desenvolvido com o objetivo de aplicar, na prática, os conhecimentos de desenvolvimento web, construindo uma aplicação por etapas.

O projeto acompanha a evolução de uma aplicação web, partindo de uma estrutura básica em HTML até a implementação de estilização, responsividade, interatividade com JavaScript, manipulação de dados JSON e consumo de uma API externa.

## 🚀 Etapas de desenvolvimento

### Fase 1 – HTML básico
- Construção da estrutura inicial da aplicação.
- Utilização de HTML.
- Sem CSS e sem JavaScript.

### Fase 2 – Estilização com CSS
- Aplicação de estilos visuais.
- Organização dos elementos da interface.
- Melhoria da apresentação visual.

### Fase 3 – Layout responsivo
- Adaptação da interface para diferentes tamanhos de tela.
- Utilização de recursos de responsividade com CSS.

### Fase 4 – JavaScript
- Implementação de funcionalidades interativas (como navegação e manipulação do DOM).
- Manipulação dos elementos HTML com JavaScript.

### Fase 5 – Integração com JSON
- Utilização de dados no formato JSON.
- Integração entre a aplicação e os dados locais.

### Fase 6 – Consumo da API ViaCEP
- Integração com a API ViaCEP.
- Consulta de endereços por meio do CEP.
- Preenchimento automático dos dados de endereço.

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **JSON**
- **API ViaCEP**

## 📚 Objetivo educacional

Demonstrar, por meio de um projeto prático e incremental, como uma aplicação web pode evoluir a partir de conceitos fundamentais de desenvolvimento até a integração com serviços externos.
